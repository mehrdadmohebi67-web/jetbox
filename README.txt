JET BOX — PWA / آخرین نسخه

این بسته برای نصب Jet Box به‌صورت اپلیکیشن وب (PWA) آماده شده است.

نکته مهم برای نسخه‌های آینده:
- آدرس انتشار باید ثابت بماند.
- هر نسخه جدید Jet Box باید index.html همین مسیر را جایگزین کند.
- کاربر لازم نیست دوباره اپ را نصب کند؛ همان آیکن، نسخه جدید را دریافت می‌کند.
- Service Worker در حالت آنلاین برای صفحه اصلی از شبکه استفاده می‌کند و نسخه تازه را در کش جایگزین می‌کند.
- در حالت آفلاین، آخرین نسخه کش‌شده باز می‌شود.

نصب روی Android:
1) بسته را روی یک وب‌سرور HTTPS با آدرس ثابت قرار دهید.
2) سایت را با Chrome باز کنید.
3) گزینه Install app / افزودن به صفحه اصلی را بزنید.

این نسخه شامل قابلیت «⚡ دسترسی سریع» برای نقش‌های مختلف Jet Box است.
